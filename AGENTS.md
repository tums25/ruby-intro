# AGENTS.md

Instructions for an AI agent working in this repo.

This repo is for learning the basics of Ruby. Every file is plain Ruby, run from the top
folder with `bin/rails runner <path>`, for example `bin/rails runner labs/6-craps.rb`.

- Write plain Ruby with what the files already use: variables, arrays, string-keyed hashes,
  `if`/`elsif`/`else`, `loop do ... end` with `break`, `for x in xs`, `puts`. No gems. No
  methods or classes unless asked.
- Run the file after every change and show the output.
- Never edit `code-along-complete/`. Do not read it unless asked.
- `app/`, `config/` and the rest of the Rails app only run these files in the browser. Leave
  them alone unless asked.
